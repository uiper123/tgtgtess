Роль: Lead Python Desktop Architect, UI/UX Designer & Cybersecurity Specialist.
Задача: Разработать архитектуру и написать чистый, готовый к продакшену код для кроссплатформенного нативного десктопного комплекса офлайн-тестирования студентов "EduTest Pro".

Приложение должно работать БЕЗ ИНТЕРНЕТА, строго внутри локальной сети (LAN) по протоколу TCP и состоять из двух независимых программ (сервер преподавателя и клиент студента). Код пишется с расчетом на последующую компиляцию через Nuitka в бинарные файлы (EXE для Windows / ELF для Linux), чтобы полностью исключить доступ студентов к исходному коду.

### 2. МОДУЛЬ ПАРСЕРА И ПОДДЕРЖКА ИЗОБРАЖЕНИЙ (shared/parser.py)
Напиши парсер, который принимает .txt файл и преобразует его в список словарей (структуру вопросов). Парадигма парсинга:
- Строка с «?N» указывает на начало вопроса. Если есть текст «(С множественным выбором)», вопрос поддерживает выбор нескольких чекбоксов.
- Маркер «@image:имя_файла.png» на отдельной строке указывает на изображение к вопросу. Парсер должен найти этот файл в той же директории, где лежит файл теста, считать его, сконвертировать в Base64-строку и записать в словарь вопроса под ключом "image_data". Если маркера нет, "image_data" равен None.
- Строка, начинающаяся с «+» — правильный вариант ответа.
- Строка, начинающаяся с «-» — неправильный вариант ответа.

Пример входящего формата файла:
?1
Какой протокол используется для защищенной передачи гипертекста в сети Интернет?
+HTTP
-HTML
-Python

?2 (С множественным выбором)
Какая топология локальной сети изображена на схеме ниже?
@image:network_star.png
+Звезда
-Кольцо
-Шина

### 3. СЕТЕВОЙ ПРОТОКОЛ (JSON over TCP)
Связь между клиентом и сервером реализуй на чистых сокетах (socket / PySide6.QtNetwork). Обмен данными происходит пакетами JSON. За счет кодирования Base64 изображения передаются прямо внутри текстового JSON:
- Запрос студента на подключение: `{"action": "connect", "name": "Иванов И.И.", "group": "ИСП-311"}`
- Ответ сервера (Успех): `{"status": "success", "questions": [{"text": "...", "image_data": "iVBORw0KGgo...", "answers": [...]}], "duration": 45}`
- Ответ сервера (Ошибка группы): `{"status": "error", "message": "wrong_group"}`
- Отправка финальных результатов клиентом: `{"action": "result", "name": "Иванов И.И.", "group": "ИСП-311", "score": "15/20"}`

### 4. ИНТЕРФЕЙС ПРЕПОДАВАТЕЛЯ (server/ui_server.py)
Реализуй современный Web-dashboard дизайн на PySide6 строго по следующему макету:
- БОКОВОЕ МЕНЮ (Sidebar): Ширина 260px, темно-серый фон (#1e202b). Внутри:
  * Логотип и подпись: "EduTest Pro / ПОРТАЛ ИНСТРУКТУРА" (белый текст, шрифт 18px).
  * Вкладки (QPushButton): "Дашборд", "Банк вопросов", "Активные экзамены" (активна по умолчанию), "Результаты студентов", "Настройки". При наведении — легкое подсвечивание синим.
  * В самом низу сайдбара: Большая синяя кнопка `[+] Создать новый тест` (#3b82f6) и индикатор `● Сервер: Активен` (зеленый текст).
- ГЛАВНАЯ ПАНЕЛЬ "Управление тестами":
  1. Верхняя карточка настроек (белый фон, скругление, тонкая серая рамка). Внутри горизонтальный ряд (QHBoxLayout):
     * Поле "Академическая группа / Класс" (QLineEdit) с плейсхолдером "напр. CS-101 Секция А".
     * Поле "Лимит времени (минуты)" (QSpinBox) со значением по умолчанию "60".
     * Фиолетово-синяя кнопка "Загрузить шаблон теста".
  2. Центральная зона Drag-and-Drop: Крупный белый блок по центру. Внутри: синяя иконка загрузки, текст "Перетащите файлы теста сюда. Поддержка .txt файлов.", а под текстом две кнопки: "Обзор файлов" и "Локальная библиотека". При перетаскивании файла .txt в эту область срабатывает парсер.
  3. Нижняя таблица "Недавно активные экзамены": QTableWidget (Название оценки | Группа | Статус | Студенты | Действие). Статусы отображать в виде скругленных цветных тегов (Badges): "Активен" (светло-зеленый фон, темно-зеленый текст), "Запланирован" (светло-желтый фон, коричневый текст). В колонке Действие — кликабельная ссылка "Мониторинг", открывающая окно отслеживания студентов по сети в реальном времени. При завершении теста данные автоматически выгружаются в файл `Результаты_[Текущая_Группа]_[Дата].csv`.

### 5. ПРОГРАММА СТУДЕНТА И БЕЗОПАСНОСТЬ (client/)
- Процесс авторизации: Экран А — ввод ФИО, Группы и IP-адреса сервера преподавателя.
- Вход в тест: Окно блокировки ПК и режим Киоска активируются ТОЛЬКО после того, как сервер прислал ответ "success". Если сервер вернул "wrong_group", выводится предупреждение: «Вы не числитесь в текущей группе тестирования».
- Режим Киоска (Kiosk Mode): При старте теста окно разворачивается на весь экран без рамок, заголовков и кнопок управления:
  `self.setWindowFlags(Qt.Window | Qt.CustomizeWindowHint | Qt.WindowStaysOnTopHint)`
  `self.showFullScreen()`
- Блокировка интерфейса: Переопредели метод `closeEvent(self, event)`, чтобы он полностью игнорировал попытки закрыть программу (`event.ignore()`), пока тест не сдан. В `keyPressEvent` полностью блокируй и игнорируй системные клавиши (Esc, Alt+F4, Ctrl+W, Windows-key).
- Прохождение теста и отображение картинок: Вопросы отображаются строго по одному. Назад вернуться нельзя. Если в вопросе есть `image_data`, декодируй строку из Base64, загрузи её в `QPixmap` и отобрази в виджете `QLabel` по центру карточки вопроса (с сохранением пропорций `Qt.KeepAspectRatio`). Если картинки нет, этот `QLabel` должен скрываться (`.hide()`), чтобы не занимать пустое место. Если вопрос одиночный — создавать QRadioButton, если множественный — QCheckBox.
- Скрытый шифрованный бэкап: При клике на «Завершить» результат отправляется на сервер, а также принудительно сохраняется локально на ПК студента в системную директорию (os.getenv('APPDATA') для Windows или ~/.config для Linux). Данные маскируются под .log файл и зашифровываются простым XOR-алгоритмом, чтобы студент не мог изменить его в Блокноте.

### 6. СТИЛИЗАЦИЯ (Полный QSS под макет)
Напиши QSS-стили, которые маскируют стандартные компоненты Qt под легкий современный веб-интерфейс:
- Главный фон приложения: Светло-серый, почти белый (`#f8fafc`).
- Карточки и панели: Чисто белый фон (`#ffffff`), радиус скругления углов `border-radius: 12px;`, тонкая аккуратная рамка `border: 1px solid #e2e8f0;`.
- Шрифты: Использовать чистые интерфейсные шрифты без засечек (Segoe UI или Inter). Заголовки — крупные и жирные (`font-weight: bold; color: #1e293b;`).
- Поля ввода (QLineEdit): Светло-серый фон (`#f9fafb`), при фокусе меняющий цвет на синий (`border: 2px solid #3b82f6;`), `padding: 10px;`.
- Таблицы (QTableWidget): Без вертикальных линий сетки, только тонкие горизонтальные разделители. Заголовки колонок — на светло-сером фоне, выравнивание по левому краю.
- Варианты ответов (QRadioButton / QCheckBox) должны иметь увеличенные отступы (`padding: 10px`) и менять фон на светло-голубой при наведении курсора.
- Крупный прогресс-бар вверху экрана студента (цвет `#10b981`), контрастный таймер (моноширинный шрифт, краснеет, если осталось меньше 2 минут).
