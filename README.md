# TTGTiSO-Test (EduTest Pro Desktop)

Кроссплатформенный комплекс офлайн-тестирования студентов с интегрированной системой прокторинга, защиты от списывания и интеллектуальным масштабированием интерфейса. 

Система работает **полностью локально (без интернета)** внутри LAN по высокопроизводительному протоколу TCP.

Состоит из двух независимых приложений: **сервер преподавателя** (управление, мониторинг и аналитика) и **клиент студента** (полноэкранный киоск-режим с блокировками). Сборка в нативные исполняемые файлы (`.exe`/`.bin`) через Nuitka исключает доступ студентов к исходному коду.

## Ключевые возможности

### 🖥 Сервер преподавателя
* **Интеллектуальный репозиторий тестов**: 
  - Удобный поиск по названию теста и группе.
  - Мгновенный фильтр по статусу (Все / Активные / Завершенные).
  - Мультирежимная сортировка (по новизне, по алфавиту, активные в топе).
* **Управление и Live-Мониторинг**:
  - Запуск нескольких экзаменов для разных групп параллельно.
  - Мониторинг прохождения теста студентами в реальном времени.
  - **Live-Лог прокторинга**: получение предупреждений о попытках переключения окон или рабочих столов студентом.
* **Импорт резервных копий результатов**:
  - Возможность ручного импорта зашифрованного файла бэкапа студента (`.log`) прямо в общую таблицу результатов преподавателя (в случае обрыва связи или форс-мажора).
* **Конструктор и Настройки сессий**:
  - Импорт тестов из `.txt` с поддержкой изображений (Drag & Drop).
  - Гибкие настройки: лимит времени, случайный порядок вопросов/ответов, количество попыток, частичный подсчет баллов.
* **Аналитика**: авторасчет оценок по гибкой шкале и мгновенный экспорт ведомости результатов в Excel-совместимый формат CSV.

### 🎓 Клиент студента
* **Автовыбор активных групп**: динамический запрос доступных экзаменов с сервера при указании IP-адреса.
* **Бескомпромиссный Режим Киоска**:
  - Автоматическое развертывание на весь экран без рамок и заголовков.
  - Аппаратное подавление системных горячих клавиш: `Escape`, `Alt+F4`, `Ctrl+W`, клавиш `Windows`/`Super`/`Meta`.
* **Активный Прокторинг (Focus Loss Detection)**:
  - Отслеживание потери фокуса окна и создания/переключения на второй рабочий стол.
  - Передача логов о списывании на сервер. При накоплении **3 нарушений** тест студента принудительно завершается с сохранением текущих ответов и блокируется.
  - **Защита от ложных срабатываний**: отложенный старт прокторинга на 1.5 секунды после полного завершения системных анимаций разворачивания экрана.
* **Пользовательский Локальный Бэкап**:
  - При завершении теста автоматически создается папка **`резервная копия/`** в директории запуска.
  - Результат сохраняется в зашифрованный файл с понятным названием: `Бэкап_[Группа]_[ФИО_Студента].log`.
  - Защита от редактирования результатов студентами (надежный XOR-шифр).

### 📐 Адаптивный дизайн и масштабирование
* **Универсальное масштабирование (UI Scaling)**:
  - Поддержка изменения масштаба элементов управления от **50%** до **200%** для комфортной работы на экранах с высоким разрешением (4K, UltraHD, HighDPI ноутбуки).
  - Настройка масштаба сохраняется в конфигурации сервера.
* **Премиум-эстетика**:
  - Современная палитра Indigo/Slate, сглаженные углы элементов (12px), микро-анимации интерактивных кнопок при наведении, контрастный таймер обратного отсчета.
  - Защита от обрезания элементов: автоматический расчет высоты ячеек таблиц (54px) и адаптивные отступы.

## Формат файла теста (`.txt`)

Текстовый файл теста должен быть в кодировке **UTF-8**. Поддерживаются одиночный и множественный выбор, а также вставка картинок.

```text
?1
Какой протокол используется для защищенной передачи гипертекста?
+HTTPS
-HTML
-Python
-FTP

?2 (С множественным выбором)
Выберите языки программирования:
+Python
+JavaScript
-HTML
-CSS
+Java

?3
Какая топология сети изображена на схеме?
@image:network_star.png
+Звезда
-Кольцо
-Шина
```

* `?N` — начало вопроса (N — номер вопроса).
* `(С множественным выбором)` — указывает, что в вопросе будет множественный выбор (чекбоксы вместо радиокнопок).
* `+` — правильный вариант ответа.
* `-` — неправильный вариант ответа.
* `@image:filename.png` — путь к картинке вопроса (картинка должна лежать в той же папке, что и файл теста). Парсер автоматически закодирует её в Base64.

## Сетевой протокол (TCP JSON)

Пакеты представляют собой байтовый массив формата: `[4 байта длины сообщения (big-endian int)][JSON-строка в UTF-8]`.
Стандартный порт: `9876`.

### Запросы клиента студента:
1. **Запрос активных групп**: `{"action": "get_active_group"}`
2. **Авторизация и подключение**: `{"action": "connect", "name": "Иванов Иван", "group": "ИСП-41"}`
3. **Отправка ответов**: `{"action": "result", "name": "Иванов Иван", "group": "ИСП-41", "answers": {"1": ["HTTPS"]}}`
4. **Сигнал прокторинга (чит-код)**: `{"action": "cheat_warning", "name": "Иванов Иван", "group": "ИСП-41", "description": "Попытка переключения рабочего стола (Предупреждение 1)"}`

## Руководство по запуску

### Шаг 1. Установка окружения
Требуется Python версии **3.10+**.

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация окружения (Linux/macOS)
source venv/bin/activate

# Активация окружения (Windows)
venv\Scripts\activate

# Установка зависимостей
pip install PySide6
```

### Шаг 2. Запуск в режиме разработки
```bash
# Запуск панели управления преподавателя
python server/main.py

# Запуск клиента студента
python client/main.py

# Или быстрый запуск отладки обоих приложений (Linux)
bash run_test.sh
```

## Сборка в независимые бинарные файлы

Для исключения списывания и распространения исходного кода приложения компилируются в нативные бинарники (`.exe` для Windows, исполняемый файл ELF для Linux) с помощью компилятора Nuitka.

### Локальная сборка
Установите компилятор Nuitka и запустите скрипт автоматической сборки:
```bash
pip install nuitka
python build_all.py
```
Собранные готовые дистрибутивы будут сохранены в каталогах `dist/server/` и `dist/student/`.

### Автоматическая сборка (CI/CD)
В проекте настроен пайплайн **GitHub Actions** (`.github/workflows/build.yml`). При каждом пуше в ветку `main` система автоматически собирает дистрибутивы под Windows и Linux.
Скачать готовые сборки можно во вкладке **Actions** в разделе **Artifacts** вашего репозитория.

## 🔐 Безопасность

Подробности — в [`SECURITY.md`](SECURITY.md). Кратко:

* Авто-обновления подписываются Ed25519, клиент **отказывается** запускать
  бинарник с невалидной или отсутствующей подписью.
* Парсер тестов защищён от path-traversal через `@image:`.
* TLS-запросы к GitHub API больше не отключают проверку сертификата —
  используется корневой store из пакета `certifi`.
* `MAX_MESSAGE_SIZE` снижен до 64 МБ, чтобы закрыть DoS-вектор.

### Как развернуть подпись обновлений
```bash
# Один раз
python scripts/generate_signing_keys.py
git add shared/update_public_key.pem
# приватный ключ → НЕ в репозиторий, держать вне git.

# При каждом релизе:
python scripts/sign_update.py dist/student/TTGTiSO-Test-student.exe
```
