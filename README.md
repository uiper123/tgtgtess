## ✨ Возможности и особенности

TTGTiSO-Test — автономный настольный комплекс для проведения зачетов, экзаменов и контрольных работ в учебных аудиториях. Сервер запускается на компьютере преподавателя, клиенты — на компьютерах учащихся.

**Полная автономность. Не требуется постоянный доступ в интернет или облачные сервисы.**

- 🖥️ **Сервер преподавателя:**
  - Встроенный визуальный конструктор тестов и поддержка простого текстового формата `.txt`.
  - Организация тестов по **каталогам и подпапкам** (по предметам, курсам и направлениям).
  - Выбор произвольной папки хранения тестов (включая сетевые папки и флеш-накопители).
  - Живой мониторинг прохождения тестирования в реальном времени.
  - Экспорт результатов в стилизованный **Excel (.xlsx)** и **CSV**.
  - Централизованная раздача обновлений на клиентские места по локальной сети.
- 🎓 **Клиент-киоск студента:**
  - Автоматическое обнаружение сервера в LAN (Zero-Config UDP Discovery).
  - Полноэкранный режим киоска с блокировкой системных сочетаний клавиш.
  - **In-App Modal Overlays:** встроенные модальные окна без рамок ОС, исключающие лазейки для открытия меню «Пуск» или переключения окон.
  - **Непрерывность тестирования при потере сети:** при обрыве связи экзамен не прерывается, а ответы автоматически отправляются при восстановлении подключения.
  - Двойной локальный бэкап ответов (зашифрованный файл + резервная копия на Рабочем столе).
- 🛡️ **Прокторинг и безопасность:**
  - Учёт потери фокуса и попыток переключения рабочих столов с лимитом предупреждений.
  - Якорь экзаменационного таймера на сервере (защита от сброса времени через переподключение).
  - Криптографически подписанные обновления с верификацией Ed25519.

## 📥 Установка и запуск

### Вариант 1. Запуск готовых сборок (Рекомендуется)

Готовые бинарные файлы скомпилированы в автономные исполняемые файлы и не требуют установки Python:

1. Перейдите в раздел **[GitHub Releases](https://github.com/uiper123/tgtgtess/releases/latest)**.
2. Скачайте файлы под вашу операционную систему:
   - **Windows:**
     - `TTGTiSO-Test-server-vX.Y.Z.exe` — панель преподавателя.
     - `TTGTiSO-Test-student-vX.Y.Z.exe` или инсталлятор `EduTestStudent_Setup-vX.Y.Z.exe` — клиент студента.
   - **Linux:**
     - `TTGTiSO-Test-server-vX.Y.Z` — панель преподавателя.
     - `TTGTiSO-Test-student-vX.Y.Z` — клиент студента.
     - Разрешите запуск в терминале: `chmod +x TTGTiSO-Test-*`.

---

### Вариант 2. Установка из исходного кода (Для разработчиков)

#### Требования:
- **Python 3.10+** (поддерживаются 3.10, 3.11, 3.12)
- Системные пакеты (для Linux): `python3-venv`, `build-essential`

#### Пошаговая установка:

```bash
# 1. Клонирование репозитория
git clone https://github.com/uiper123/tgtgtess.git
cd tgtgtess

# 2. Создание и активация виртуального окружения
python3 -m venv .venv

# Для Linux:
source .venv/bin/activate

# Для Windows (PowerShell):
# .venv\Scripts\Activate.ps1

# 3. Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

#### Запуск:

```bash
# Сервер преподавателя:
python -m server.main

# Клиент студента:
python -m client.main
```

## ⚙️ Настройка и руководство пользователя

### 1. Настройка сети и брандмауэра

Компьютеры преподавателя и студентов должны быть подключены к одной локальной сети (проводная сеть или Wi-Fi).

| Протокол | Порт | Назначение |
|---|---|---|
| **TCP** | **9876** (настраивается) | Авторизация, передача вопросов, мониторинг, получение результатов, раздача обновлений |
| **UDP** | **9877** | Широковещательный маяк (Discovery Beacon) для мгновенного авто-поиска сервера клиентами |

> **Настройка Firewall:** На компьютере преподавателя разрешите входящие подключения для приложения или портов **TCP 9876** и **UDP 9877**.

---

### 2. Структура и организация тестов (Каталоги и подпапки)

Тесты хранятся в формате `.txt` (кодировка UTF-8). Базу тестов можно группировать по папкам предметов, семестров и специальностей:

```text
tests_repo/
├── Информатика/
│   ├── Тест_1_Основы_алгоритмизации.txt
│   └── Итоговый_экзамен.txt
├── Программирование_Python/
│   ├── Модуль_1_Синтаксис.txt
│   └── Курсовой_зачет.txt
└── Входное_тестирование.txt
```

- В таблице «Все тесты» папки отображаются в колонке **«Каталог / Тест»**.
- В настройках сервера можно указать любую директорию для хранения тестов (кнопка *«Выбрать папку»*).

---

Тесты можно создавать как через визуальный редактор в интерфейсе сервера, так и в любом текстовом редакторе:

### 4. Проведение тестирования и прокторинг

1. **Запуск экзамена:**
   - На сервере перейдите в раздел **«Запуск тестирования»**.
   - Выберите тест, укажите группу (например, `ИСП-311`), лимит времени и допустимое число нарушений.
   - Нажмите **«Запустить тестирование»**.
2. **Вход студентов:**
   - Студент запускает клиент. IP сервера определится автоматически через UDP.
   - Студент вводит ФИО, выбирает свою группу и нажимает «Подключиться».
3. **Режим киоска:**
   - Окно студента разворачивается на весь экран без системных рамок.
   - Блокируются комбинации клавиш `Alt+Tab`, `Win`, `Ctrl+Esc` и попытки свернуть окно.
   - При потере фокуса окно принудительно восстанавливается, фиксируется предупреждение, передаваемое на сервер.
4. **Результаты:**
   - Оценки отображаются в реальном времени у преподавателя.
   - Поддерживается экспорт в **Excel (.xlsx)** и **CSV**.

---

### 5. Отказоустойчивость и автономный режим (Offline Continuity)

В системе реализована защита от сбоев локальной сети и случайного отключения Wi-Fi:

- **При потере связи во время теста:** Экзамен **не прерывается**, киоск не закрывается, таймер продолжает отсчет, а вверху экрана отображается статус автономного режима и номер попытки переподключения.
- **При завершении теста без связи:** Результаты надёжно сохраняются в зашифрованный локальный бэкап и в резервную копию на Рабочем столе. Фоновый процесс продолжает попытки отправить ответы преподавателю.
- **Авто-восстановление:** Как только связь восстанавливается, клиент автоматически отправляет ответы на сервер, преподаватель получает результат, а студент видит итоговую оценку.

## 🔄 Обновление программы

TTGTiSO-Test оснащен встроенной системой бесшовного обновления сервера и клиентских машин.

### Как работает автоматическое обновление

1. **Умная фильтрация по ОС:** Сервер проверяет свежий релиз на GitHub и скачивает **только** бинарники под ОС сервера и подключенных студентов. Установочные пакеты (`Setup.exe`) и бинарники чужих ОС не загружаются, экономя трафик.
2. **Централизованная раздача по LAN:** Преподаватель нажимает «Обновить все» — сервер передает пакеты обновления всем подключенным студентам по локальной сети.
3. **Бесшовная замена:** Приложение запускает фоновый процесс обновления, закрывается, заменяет исполняемый файл на новую версию и автоматически перезапускается.

---

### Пошаговая инструкция по обновлению

1. Откройте панель преподавателя и перейдите в **«Настройки»**.
2. В блоке обновлений нажмите **«Проверить обновления»** (при наличии новой версии появится уведомление).
3. Нажмите **«Загрузить обновления»** — откроется окно с прогресс-баром загрузки.
4. После завершения загрузки нажмите **«Обновить все»**.
5. Сервер разошлет обновления студентам и перезапустится в обновленной версии.

---

### Безопасность и цифровая подпись Ed25519

Все бинарные файлы обновлений защищены криптографической подписью **Ed25519**:
- При первом подключении студент запоминает открытый ключ сервера (Trust On First Use — TOFU).
- Перед применением любого обновления клиент проверяет контрольную сумму **SHA-256** и цифровую подпись.
- Это гарантирует 100% защиту от подмены файлов и атак типа Man-in-the-Middle (MITM) в локальной сети.
