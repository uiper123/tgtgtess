# TTGTiSO-Test

Кроссплатформенный комплекс офлайн-тестирования студентов. Работает **без интернета**, строго внутри локальной сети (LAN) по протоколу TCP.

Состоит из двух независимых приложений: **сервер преподавателя** и **клиент студента**. Собирается в нативные бинарники через Nuitka — студенты не имеют доступа к исходному коду.

---

## Архитектура

```
Преподаватель (сервер)              Студент (клиент)
┌─────────────────────┐            ┌──────────────────┐
│  Загрузка теста     │            │  Ввод ФИО, группы│
│  Настройка экзамена │◄──TCP/IP──►│  и IP сервера    │
│  Мониторинг         │   JSON     │  Прохождение     │
│  Результаты + CSV   │   порт     │  теста в режиме  │
│                     │   9876     │  киоска          │
└─────────────────────┘            └──────────────────┘
```

## Возможности

### Сервер преподавателя
- Загрузка тестов из `.txt` файлов (drag & drop)
- Запуск нескольких экзаменов для разных групп одновременно
- Мониторинг студентов в реальном времени
- Настройка: лимит времени, случайный порядок, количество попыток, частичный подсчёт
- Автоматический экспорт результатов в CSV
- Редактор и банк вопросов
- Полная история результатов

### Клиент студента
- Автоопределение активных групп при вводе IP
- Режим киоска: полноэкранное окно без возможности выхода
- Блокировка Esc, Alt+F4, Ctrl+W, Windows-key
- Поддержка изображений в вопросах (Base64)
- Одиночный и множественный выбор
- Таймер с обратным отсчётом
- Шифрованный локальный бэкап результатов

## Сетевой протокол

Обмен данными — JSON поверх TCP. Каждый пакет: `[4 байта длины (big-endian)][JSON UTF-8]`.

| Направление | Действие | Пример |
|---|---|---|
| Клиент → Сервер | Запрос групп | `{"action": "get_active_group"}` |
| Клиент → Сервер | Подключение | `{"action": "connect", "name": "Иванов", "group": "ПД-25"}` |
| Сервер → Клиент | Успех + тест | `{"status": "success", "questions": [...], "duration": 60}` |
| Клиент → Сервер | Результаты | `{"action": "result", "name": "...", "answers": {...}}` |
| Сервер → Клиент | Подтверждение | `{"status": "result_confirmed", "score": "15/20"}` |

**Порт по умолчанию:** `9876`

## Формат файла теста (.txt)

```
?1
Какой протокол используется для защищенной передачи гипертекста?
+HTTPS
-HTML
-Python
-FTP

?2 (С множественным выбором)
Выберите языки программирования:
+Python
+JavaScript
-HTML
-CSS
+Java

?3
Какая топология сети изображена на схеме?
@image:network_star.png
+Звезда
-Кольцо
-Шина
```

- `?N` — начало вопроса (N — номер)
- `(С множественным выбором)` — множественный выбор (чекбоксы вместо радиокнопок)
- `+` — правильный ответ
- `-` — неправильный ответ
- `@image:файл.png` — изображение к вопросу (из той же папки, что и файл теста)

## Запуск для разработки

### Установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate   # Linux/macOS
# venv\Scripts\activate    # Windows
pip install PySide6
```

### Запуск

```bash
# Сервер преподавателя
python server/main.py

# Клиент студента (на другом ПК или терминале)
python client/main.py

# Или оба сразу (Linux)
bash run_test.sh
```

## Сборка бинарников

### Автоматически (GitHub Actions)

При каждом пуше в `main`/`master` GitHub Actions автоматически собирает:
- **Windows:** `edutest-server.exe`, `edutest-student.exe`
- **Linux:** `edutest-server`, `edutest-student`

Готовые бинарники доступны во вкладке **Actions → Artifacts**.

### Локально

```bash
pip install nuitka
python build_all.py
```

Результат в `dist/server/` и `dist/student/`.
