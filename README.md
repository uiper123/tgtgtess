## ✨ Возможности и особенности

TTGTiSO-Test — автономный настольный комплекс для проведения зачетов, экзаменов и контрольных работ в учебных заведениях. Сервер запускается у преподавателя, клиенты — на компьютерах студентов.

**Полная автономность. Никакого внешнего интернета или облачных сервисов.**

- 🖥️ **Сервер преподавателя:**
  - Встроенный визуальный конструктор тестов и поддержка текстового формата `.txt`.
  - Организация тестов по **каталогам и подпапкам** (по предметам, курсам и направлениям).
  - Выбор произвольной папки хранения базы тестов прямо из настроек.
  - Мониторинг прохождения тестирования в реальном времени.
  - Экспорт результатов в стилизованный **Excel (.xlsx)** и **CSV**.
- 🎓 **Клиент-киоск студента:**
  - Автоматическое обнаружение сервера в локальной сети (Zero-Config UDP Discovery).
  - Полноэкранный Kiosk-режим с блокировкой системных сочетаний клавиш.
  - **In-App Modal Overlays:** встроенные модальные окна предупреждений и подтверждения без нативных рамок ОС, исключающие лазейки для открытия меню «Пуск» или переключения окон.
  - Двойной локальный бэкап ответов (включая автоматическое сохранение копии на Рабочий стол студента).
- 🛡️ **Прокторинг и безопасность:**
  - Учёт потери фокуса и попыток переключения рабочих столов с настраиваемым лимитом предупреждений.
  - Якорь экзаменационного таймера (защита от сброса времени через переподключение).
  - Подписанные авто-обновления с криптографической проверкой подписи Ed25519.

## 📥 Установка и запуск

### Вариант 1. Запуск готовых сборок (Рекомендуется)

Готовые бинарные файлы не требуют установки Python и сторонних библиотек:

1. Перейдите на страницу **[Releases](https://github.com/uiper123/tgtgtess/releases/latest)**.
2. Скачайте сборку под вашу операционную систему:
   - **Windows:** `TTGTiSO-Test-server-vX.Y.Z.exe` (для преподавателя) и `TTGTiSO-Test-student-vX.Y.Z.exe` (для студентов).
   - **Linux:** `TTGTiSO-Test-server-vX.Y.Z` и `TTGTiSO-Test-student-vX.Y.Z` (перед запуском сделайте исполняемым: `chmod +x TTGTiSO-Test-*`).

---

### Вариант 2. Установка из исходного кода (Для разработчиков и администраторов)

#### Требования:
- **Python 3.10+** (проверено на 3.10, 3.11, 3.12)
- Библиотеки Qt / PySide6, Pillow, openpyxl, cryptography, certifi

#### Пошаговая установка:

```bash
# 1. Клонирование репозитория
git clone https://github.com/uiper123/tgtgtess.git
cd tgtgtess

# 2. Создание и активация виртуального окружения
python3 -m venv .venv

# Для Linux / macOS:
source .venv/bin/activate

# Для Windows (PowerShell / CMD):
# .venv\Scripts\Activate.ps1   или   .venv\Scripts\activate.bat

# 3. Установка основных и dev-зависимостей
pip install --upgrade pip
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

#### Запуск:

```bash
# Запуск сервера преподавателя:
python -m server.main

# Запуск клиента студента:
python -m client.main
```

## ⚙️ Настройка и руководство пользователя

### 1. Настройка сети и брандмауэра

Компьютеры преподавателя и студентов должны находиться в одной локальной сети (LAN / Wi-Fi).

| Протокол | Порт | Назначение |
|---|---|---|
| **TCP** | **9876** (настраивается) | Основной канал связи: авторизация, передача вопросов и результатов |
| **UDP** | **9877** | Широковещательный маяк (Discovery Beacon) для авто-поиска сервера |

> **Примечание по Firewall:** В Windows Брандмауэре или `ufw`/`iptables` на Linux разрешите входящие подключения к серверу преподавателя по портам **TCP 9876** и **UDP 9877**.

---

### 2. Структура и организация тестов (Каталоги и подпапки)

Тесты хранятся в формате `.txt` (UTF-8). Вы можете структурировать базу тестов по вложенным папкам в директории тестов (по умолчанию `tests_repo/`):

```text
tests_repo/
├── Информатика/
│   ├── Тест_1_Основы_алгоритмизации.txt
│   └── Итоговый_тест.txt
├── Программирование_Python/
│   ├── Модуль_1.txt
│   └── Экзамен_2026.txt
└── Входное_тестирование.txt
```

- **В интерфейсе сервера:** В таблице «Все тесты» колонка **«Каталог / Тест»** наглядно отображает структуру.
- **При выборе теста:** В диалоге «Выбрать тест из репозитория» каталог и имя теста вынесены в отдельные колонки для быстрого поиска и фильтрации.
- **Пользовательская папка тестов:** В разделе **«Настройки» → «Папка с тестами»** можно указать любую удобную директорию (включая сетевые диски или флеш-накопители).

---

### 3. Формат файла теста (.txt)

Тесты можно создавать как в визуальном конструкторе сервера, так и в любом текстовом редакторе в формате UTF-8:

```text
@title: Итоговая контрольная работа
@section: Основы компьютерных сетей

?1
Какой протокол отвечает за надежную доставку данных с установлением соединения?
+ TCP
- UDP
- IP
- ICMP

?2
Какие из перечисленных протоколов относятся к прикладному уровню модели OSI? (несколько ответов)
*
+ HTTP
+ DNS
+ SSH
- Ethernet
- ARP

?3 (Письменный ответ)
Укажите стандартный порт протокола HTTPS.
+ 443

?4
Вставьте пропущенное слово:
Процесс преобразования доменного имени в IP-адрес называется {DNS|разрешением имен}.

?5
Установите соответствие между протоколом и его назначением:
+ HTTP -> Передача гипертекста
+ SMTP -> Отправка электронной почты
+ FTP -> Передача файлов

?6
Расположите единицы измерения информации в порядке возрастания:
+ Байт
+ Килобайт
+ Мегабайт
+ Гигабайт

?7
Что выведет фрагмент схемы?
@image: network_topology.png
+ Сеть класса C
- Сеть класса A
```

**Поддерживаемые типы заданий:**
- **Одиночный выбор:** варианты с `+` (верный) и `-` (неверные).
- **Множественный выбор:** строка `*` перед вариантами ответов.
- **Письменный / свободный ввод:** `?N (Письменный ответ)` и список допустимых вариантов с `+`.
- **Пропуски в тексте (Fill-in-the-blanks):** пропуски обозначаются `{вариант1|вариант2}`.
- **Соответствия (Matching):** строки вида `+ Элемент 1 -> Элемент 2`.
- **Упорядочивание (Ordering):** элементы с `+` в правильной последовательности.
- **Иллюстрации к вопросам:** тег `@image: filename.png` (изображение кладется рядом с файлом теста).

### 4. Проведение тестирования и прокторинг

1. **Запуск экзамена преподавателем:**
   - На сервере перейдите во вкладку **«Запуск тестирования»**.
   - Нажмите «Выбрать из репозитория» или выберите тест на Дашборде.
   - Укажите группу студентов (например, `ИСП-24`), длительность в минутах и допустимый лимит нарушений (по умолчанию 3).
   - Нажмите **«Запустить тестирование»**.
2. **Подключение студентов:**
   - Студент запускает клиент.
   - Сервер обнаруживается автоматически (поле IP заполнится само, либо можно ввести вручную).
   - Студент вводит ФИО, выбирает свою группу и нажимает «Подключиться».
3. **Прохождение и защита киоска:**
   - Окно студента переходит в полноэкранный режим без рамок ОС.
   - Защита отслеживает попытки переключения окон, открытия меню «Пуск» или сворачивания.
   - При нарушении полноэкранный фокус немедленно восстанавливается, фиксируется предупреждение, а данные передаются на сервер.
   - При завершении теста выводится защищенный внутренний оверлей с информацией о количестве отвеченных вопросов и подтверждением отправки.
4. **Результаты и резервные копии:**
   - Преподаватель видит результаты в реальном времени на вкладках «Активные тестирования» и «Результаты студентов».
   - Доступен экспорт ведомостей в **Excel (.xlsx)** и **CSV**.
   - У студента автоматически создается резервная копия результатов на Рабочем столе (`Рабочий стол/edutest_backup_...`).

## 🛠 Разработка и тестирование

### Запуск тестов:

```bash
# Запуск полного набора unit- и интеграционных тестов:
pytest

# Запуск тестов с подробным выводом:
pytest -v

# Проверка стиля и качества кода:
ruff check .
```

### Сборка исполняемых файлов через Nuitka:

```bash
# Сборка сервера (Windows / Linux):
nuitka --standalone --onefile --enable-plugin=pyside6 --include-package=openpyxl --include-package=cryptography --include-package=PIL --output-dir=dist server/main.py

# Сборка клиента:
nuitka --standalone --onefile --enable-plugin=pyside6 --include-package=cryptography --include-package=PIL --output-dir=dist client/main.py
```

```text
tgtgtess/
├── server/                 # Сервер преподавателя
│   ├── main.py             # Точка входа, TCP-сервер (QTcpServer), UDP-маяк

│   ├── ui_server.py        # Главное окно сервера и навигация
│   ├── ui_dashboard.py     # Дашборд со списком тестов и быстрыми действиями
│   ├── ui_exams.py         # Запуск экзаменов и таблица активных групп
│   ├── ui_questions.py     # Визуальный конструктор и редактор тестов
│   ├── ui_results.py       # Результаты студентов, аналитика, экспорт в Excel/CSV
│   ├── ui_dialogs.py       # Модальные окна (выбор теста, мониторинг, папки)
│   └── styles.py           # Тема оформления сервера
├── client/                 # Клиент-киоск студента
│   ├── main.py             # Сетевой TCP-клиент, локальный шифрованный бэкап
│   ├── ui_client.py        # GUI студента, Kiosk mode, In-App Modal Overlays
│   └── styles.py           # Тема оформления клиента
├── shared/                 # Общие модули
│   ├── parser.py           # Парсер тестов .txt, подсчет баллов, сериализация
│   ├── protocol.py         # Сетевой протокол, упаковка пакетов, discovery
│   ├── security.py         # Ed25519 подпись и проверка обновлений
│   └── styles.py           # Общие стили и хелперы
├── tests/                  # Набор тестов (82 теста)
├── scripts/                # Скрипты генерации ключей и подписи сборок
```
