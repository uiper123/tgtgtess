## [1.4.0] — 2026-05-28

Большой релиз: подписанные обновления, защита от читерства через
переподключение, чистка UI, 63 теста, и пачка мелких фиксов.

### 🔐 Security
- **Ed25519-подпись авто-обновлений.** Клиент v1.4.0+ отказывается
  запускать `.new` без валидной подписи. Закрывает RCE через фейковый
  сервер в той же LAN.
- **Якорь экзаменационного таймера.** Время измеряется от `exam_start_time`
  в `attempts`, а не от `connect_time` сокета — студент больше не может
  получить лишнее время, выдернув Wi-Fi и переподключившись.
- Атомарная запись `results.json` (через `tempfile + os.replace + fsync`):
  крах процесса больше не теряет всю историю.
- Path-traversal в `@image:` парсера тестов закрыт (`@image:../../etc/passwd`
  отвергается).
- TLS-запросы к GitHub API больше не отключают проверку сертификата
  (используется `certifi`).
- `MAX_MESSAGE_SIZE` снижен с 500 МБ до 64 МБ — закрывает DoS-вектор.
- Дебаунс focus-loss событий (2 сек): системные всплывашки больше не
  считаются за 3 нарушения подряд.

### ✨ Features
- **Конфигурируемый лимит нарушений прокторинга** — отдельный спин-бокс
  «Нарушений» на странице запуска экзамена (1–20, по умолчанию 3).
- Полный обзор системы обновлений: единый метод `send_update_to_socket`
  с подписью, sidecar-метаданные (`.new.sha256` + `.new.sig`) для повторной
  проверки перед запуском, проверки места на диске и прав на запись.
- Версия теперь видна везде в UI: заголовки окон, плашка в сайдбаре
  сервера, футер логин-экрана клиента, диалог обновления.

### 🐛 Bug fixes
- **Сломанный импорт** `get_scaled_qss` в `ui_dialogs.py` и `ui_server.py`
  (искали в локальном `styles.py`, а функция в `shared/styles.py`).
- Кнопка «Подключиться к тестированию» обрезалась на любом размере —
  карточка имела `setFixedWidth(420)`. Теперь адаптивно `min 380, max 520`.
- Карточки login и результата плавали наверху больших экранов вместо
  центрирования — добавлены `addStretch` сверху/снизу.
- Стрелки QComboBox («Все статусы», «Сортировка», «Группа») вообще
  не рендерились (`data:image/svg+xml;base64` URI Qt не загружает).
  Перешли на реальные SVG в `shared/icons/` через хелпер
  `inject_icon_paths()`.
- Колонка «Набранные баллы» в таблице результатов резалась до
  «абранные балл» (130 → 160 px).
- Цвет «Сервер: Выключен» в сайдбаре — был почти не читаем (`#64748b`
  на тёмно-синем). Поднят до `#cbd5e1`.
- Updater клиента: `update.bat`/`.sh` теперь пишется в `%TEMP%` через
  `tempfile.mkstemp`, а не в текущей рабочей директории (которая может
  быть `C:\Windows\System32` при запуске из меню Пуск).
- Updater корректно работает с путями содержащими пробелы (`Program Files`).
- `update_apply` без `.new` файла теперь логирует понятную ошибку
  вместо тихого падения.
- Минимальный размер окна сервера снижен с 1200×750 до 980×640 —
  помещается на старых ноутбуках 1024×768.

### 🚚 Миграция со старых клиентов
**Никаких ручных действий не требуется** — клиенты v1.3.6 и старше
не имеют проверки подписи в коде, поэтому при первом подключении к
v1.4.0-серверу автоматически получают и применяют обновление. Они станут
v1.4.0 с встроенным публичным ключом, после чего начнут требовать подпись
для всех будущих обновлений. Подробности — в [SECURITY.md](SECURITY.md).


### 🔐 Security
- **Подпись авто-обновлений (Ed25519).** Сервер подписывает каждый рассылаемый бинарник; клиент отказывается запускать обновление с отсутствующей или невалидной подписью. См. `shared/security.py`, `scripts/sign_update.py`, `scripts/generate_signing_keys.py`.
- **Path traversal в `@image:` запрещён.** Парсер теперь нормализует путь и не выходит за пределы директории с тестом.
- **`MAX_MESSAGE_SIZE` снижен** с 500 МБ до 64 МБ — закрывает простой DoS на стороне сервера и клиента.
- **Verified TLS.** Обращение к GitHub API больше не использует `ssl._create_unverified_context()`. Корневые сертификаты берутся из пакета `certifi`.
